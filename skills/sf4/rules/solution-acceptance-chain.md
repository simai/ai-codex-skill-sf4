# Solution Technology Acceptance Chain

When an existing SF4 solution is adapted to a client design, do not start from
an ad-hoc route or standalone page. Pass the chain in order:

1. site settings baseline;
2. section/page properties;
3. view/block mapping;
4. dynamic data analogy;
5. functional gap / module decision.

A page that works by smoke but bypasses this chain is only a technical
prototype. Method and gate details: `references/solution-customization-technology.md`.
